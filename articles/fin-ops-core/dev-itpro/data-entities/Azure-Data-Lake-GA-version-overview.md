# Export to Azure Data Lake (deprecated)

[!include [banner](../includes/banner.md)]

> [!IMPORTANT]
> Export to Azure Data Lake was retired on November 1, 2024, and will be permanently stopped on November 30, 2026. After the service is stopped, it will no longer export new or changed data. Files that were already exported to your data lake remain in place. Extensions won't be granted after November 30, 2026.

This article is retained for historical reference. Export to Azure Data Lake was a finance and operations environment add-in installed through Microsoft Dynamics Lifecycle Services. It used change data capture (CDC) to export CSV files to a customer-managed data lake.

If you still depend on Export to Azure Data Lake, transition to Link to Microsoft Fabric with low-latency sync by November 30, 2026. Link to Fabric is the recommended replacement. To plan your migration, see [Transition from legacy data integration services to Fabric link and Azure Synapse Link for Dataverse](/power-apps/maker/data-platform/azure-synapse-link-transition-from-fno). To configure the replacement service, see [Link to Microsoft Fabric](/power-apps/maker/data-platform/fabric-link-to-data-platform).
