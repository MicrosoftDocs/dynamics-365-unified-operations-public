# Create and open job requisition

[!INCLUDE [banner](../includes/banner.md)]

[!include [Applies to Human Resources](../includes/applies-to-hr.md)]

Recruitment projects help you manage your recruiting process. After creating a recruitment project, you can complete the following tasks:

- Write a job advertisement for the project.
- Publish the ad on Employee self-service pages.
- Associate applications for employment with the project.
- Track activities for that project.

1. Go to **Human resources > Recruitment > Recruitment projects > Recruitment projects**.
1. Select **New**.
1. In the **Recruitment project** field, enter a value.
1. In the **Description** field, enter a value.
1. In the **Recruiter** field, select the dropdown button to open the lookup.
1. In the list, find and select your record.
1. In the list, select the link in the selected row.
1. Choose **Select**.
1. In the **Department** field, select the dropdown button to open the lookup.
1. In the list, select the link in the selected row.
1. In the **Job** field, select the dropdown button to open the lookup.
1. In the list, find and select your record.
1. In the list, select the link in the selected row.
1. In the **Number of openings field**, enter a number.
1. In the **Hiring manager** field, select the dropdown button to open the lookup.
1. In the list, find and select your record.
1. In the list, select the link in the selected row.
1. Choose **Select**.
1. In the **Application deadline** field, enter a date.
1. Select **Media**. Recruitment projects include the option to specify media outlets to use to advertise open positions.  
1. Select **New**.
1. In the **Media** field, select the dropdown button to open the lookup.
1. In the list, select the link in the selected row.
1. In the **Start date** field, enter a date.
1. In the **End date** field, enter a date.
1. Select **Save**.
1. Close the page.
1. Select **Job ads**.
1. Select **Save**.
1. Close the page.
1. Select the **Display on Employee self service** checkbox. This selection makes the recruitment project visible to employees on their **Employee self service** page.
1. Select **Recruitment project status**.
1. Select **Start**. The **Started** status means that the project is ready to receive applications.  
1. Select **OK**.
