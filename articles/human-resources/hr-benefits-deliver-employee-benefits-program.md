# Deliver employee benefits program

[!INCLUDE [banner](../includes/banner.md)]


[!include [Applies to Human Resources](../includes/applies-to-hr.md)]

This article explains how to create benefit elements that you use when creating a new benefit. The demo data company used to create this task is USMF. This task is intended for a Compensation and Benefits manager.

## Create benefit elements

1. Go to the **Benefits** list page.
1. Select **New**.
1. In the **Type** field, enter the name of the type of benefit you're creating.
1. In the **Description** field, enter a value.
1. In the **Concurrent enrollment** field, select an option.
    * To restrict employees' ability to enroll in multiple medical plans, select **One enrollment per type**.  
1. In the **Payroll category** field, select an option.
1. Select the **Plans** tab.
1. Select **New**.
1. In the **Plan** field, enter a value.
1. In the **Description** field, enter a value.
1. In the **Type** field, select the drop-down button to open the lookup.
1. In the list, find and select the record you want.
1. In the list, select the link in the selected row.
1. In the **Payroll impact** field, select an option.
1. Select the **Options** tab.
1. Select **New**.
1. In the **Option** field, enter a value.
1. In the **Description** field, enter a value.

## Create a benefit

1. Go to **Human resources** > **Benefits** > **Benefits**.
2. Select **New**.
1. In the **Plan** field, select the drop-down button.
1. Find and select the desired record from the list.
1. Select the link in the selected row.
1. In the **Option** field, select the drop-down button.
1. Find and select the desired record from the list.
1. Select the link in the selected row.
1. Enter a date and time in the **Effective** field.
1. Select **Create benefit**.
1. Toggle the expansion of the **Payroll details** section.
1. In the **Frequency** field, select the drop-down button.
1. Find and select the desired record from the list.
1. Select the link in the selected row.
1. Select an option in the **Basis** field.
1. Enter a number in the **Amount or rate** field.
