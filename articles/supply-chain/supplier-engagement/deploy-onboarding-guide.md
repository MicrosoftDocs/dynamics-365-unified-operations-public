# Onboard using the onboarding guide (preview)

[!include [banner](../includes/banner.md)]

[!INCLUDE [preview-banner](~/../shared-content/shared/preview-includes/preview-banner.md)]

The onboarding guide gives administrators a single place to track Supplier Engagement setup progress. It brings together the core deployment activities, helps you understand what still needs attention, and makes it easier to return to incomplete tasks later. Use it throughout deployment instead of managing setup with a separate checklist.

## Open the onboarding guide

Open the onboarding guide from the Supplier Engagement app whenever you want to review setup status or continue deployment work.

1. Sign in to the Supplier Engagement app by using the service account that you're using for installation.
1. At the bottom of the navigation pane, select the **Configuration** area.
1. Under **Onboarding**, select **Onboarding Guide**.
1. Review the onboarding checklist that opens.

The onboarding guide remains available during the full setup process, so you can return to it at any time and continue where you left off.

## Use the onboarding guide

Each onboarding activity points to a specific configuration area, such as Supply Chain Management setup, Power Pages setup, cloud flow activation, or notification setup.

1. Select an onboarding activity in the left pane to review its setup instructions.
1. Use the linked Supplier Engagement documentation for additional context when you need it.
1. Complete the required configuration outside the onboarding guide.
1. Select the checkbox next to the activity after you verify that the task is complete.
1. Clear a checkbox if more work is required.

Progress is saved automatically, and the completion status is retained across sessions.

## Best practices

Use the following practices to keep onboarding organized and accurate:

- Complete onboarding activities in the recommended order.
- Mark activities as complete only after you verify the related configuration.
- Review the onboarding guide periodically to confirm that no required tasks were missed.
- If you need more detailed setup guidance for a specific activity, refer to this and other related documentation articles on Microsoft Learn.
